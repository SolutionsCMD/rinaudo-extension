# Mizkif Global browser extension

The browser extension for Mizkif Global. It earns tickets for likes, comments and watches on
Mizkif's posts, lets you vote in live polls, and tells you when Mizkif goes live or posts.

This repository holds the code exactly as it ships in each release.

- **Install:** [mizkif.com/downloads](https://mizkif.com/downloads) (Chrome, Edge, Firefox, Safari on iPhone)
- **Privacy:** what the extension reads and sends is listed in [privacy.html](privacy.html)
- **Current version:** 1.208
